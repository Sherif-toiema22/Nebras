# الخطوة 1: بناء هيكل الخلفية

## ماذا فعلنا؟
- صممنا مخطط PostgreSQL (24 جدولًا) يغطي المراحل 1 إلى 3 (`V1__init.sql`).
- أنشأنا مشروع Spring Boot 3 (Java 21) بالدخول بـ JWT، والفصول، والحضور، وربط ولي الأمر، والإشعارات.
- أضفنا `docker-compose.yml` لتشغيل PostgreSQL محليًا.

## لماذا؟
نبدأ بأصغر وظيفة لها قيمة كاملة: المعلم يسجل غيابًا فيصل إشعار لولي الأمر. المخطط كله مكتوب مبكرًا لتفادي إعادة التصميم، لكن الكود يستخدم 6 جداول فقط الآن ([ADR-0002](../adr/0002-postgresql-flyway.md)).

## كيف نتحقق؟
شغّل سيناريو الـ curl في [runbook.md](../runbook.md): ولي الأمر يرى إشعار الغياب، ومعلم آخر يحصل على 403 عند طلب بيانات الطالب.

## النتيجة
**غير مجرَّب بعد.** الكود كُتب في بيئة بلا Java أو PostgreSQL، فلم يُترجم ولم يُشغَّل. المتوقع تصحيحات صغيرة عند أول تشغيل.
