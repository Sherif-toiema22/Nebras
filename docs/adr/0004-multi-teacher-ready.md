# ADR-0004: تصميم يصلح لأكثر من مدرس (بدون بناء الجانب التجاري)

- **الحالة:** مقترح، ينتظر التنفيذ
- **التاريخ:** 2026-11

## السياق
قد يُباع النظام لمدرسين آخرين لاحقًا. تغيير العزل بين المدرسين بعد بناء كل الميزات مكلف.

## القرار
نجعل **المدرس هو مالك المحتوى** من الآن، دون بناء تسجيل ذاتي أو دفع أو باقات.
1. الجداول المعلّقة بالفصل (حضور، تقييم، اختبارات، واجبات) معزولة أصلًا عبر `classrooms.teacher_id`.
2. نضيف عمود **المالك (teacher_id)** للجداول العامة حاليًا: بنك الأسئلة، كتاب الشهر، الاشتراكات.
3. دور `ADMIN` يصبح "مدير المنصة"، والمعلم هو مدير مساحته.
4. أي استعلام جديد يُفلتر بالمدرس المالك، ويدخل في اختبارات الصلاحيات.

## البدائل
- مشروع منفصل لكل مدرس: عزل كامل لكن صيانة مكررة.
- قاعدة بيانات (Schema) لكل مدرس: أعقد في الإدارة.

## النتائج
- (+) نبيع لمدرس ثانٍ دون إعادة بناء القاعدة.
- (-) كل استعلام يحتاج فلتر مالك، والنسيان يسرّب بيانات بين المدرسين، لذلك نضع اختبارًا يتأكد من العزل.
