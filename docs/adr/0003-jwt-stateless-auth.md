# ADR-0003: JWT بدون جلسات + فحص الملكية في الخادم

- **الحالة:** مقبول
- **التاريخ:** 2026-11

## القرار
- تسجيل الدخول يُرجع توكن JWT (12 ساعة). الخادم لا يحفظ جلسات.
- كل طلب يُفحص مرتين: **الدور** عبر `@PreAuthorize`، ثم **الملكية** عبر `Access` (المعلم لفصله فقط، وولي الأمر لأبنائه فقط، والطالب لنفسه).
- الواجهة لا يُعتمد عليها في الحماية.
- الأسرار (`JWT_SECRET`، كلمة سر المدير) من متغيرات البيئة، وطول السر لا يقل عن 32 بايت.

## البدائل
- جلسات في الخادم: أبسط في الإلغاء لكنها أصعب في التوسع.
- OAuth/جهة خارجية: زيادة تعقيد بلا حاجة الآن.

## النتائج
- (+) خادم بلا حالة، يسهل توسيعه.
- (-) لا يمكن إلغاء توكن قبل انتهائه.
- (-) لا Refresh token بعد: المستخدم يسجل الدخول كل 12 ساعة.
- (-) لا حد لمحاولات الدخول الفاشلة بعد. **مطلوب قبل الإطلاق.**
