# دليل التشغيل

## تشغيل محلي
```bash
cd backend
docker compose up -d
```
ثم ضع الأسرار في **نفس نافذة الطرفية** (ويندوز PowerShell):
```powershell
$env:JWT_SECRET = "نص-عشوائي-طويل-لا-يقل-عن-32-حرفًا"
$env:ADMIN_PASSWORD = "كلمة-قوية-8-أحرف-على-الأقل"
mvn spring-boot:run
```
ماك/لينكس:
```bash
export JWT_SECRET="$(openssl rand -base64 48)"
export ADMIN_PASSWORD="كلمة-قوية"
mvn spring-boot:run
```
**النجاح:** يظهر سطر `تم إنشاء حساب المدير` وسطر `Started NebrasApplication`.

## سيناريو التحقق الأساسي
راجع قسم "تجربة سريعة" في `backend/README.md`. النتيجة المطلوبة:
1. المعلم يسجل غياب طالب.
2. ولي الأمر يدخل ويرى إشعارًا.
3. معلم آخر يطلب بيانات الطالب فيحصل على **403**.

## المتغيرات
| المتغير | الوصف |
|---|---|
| `JWT_SECRET` | سر توقيع التوكن (إجباري، 32 بايت فأكثر) |
| `ADMIN_PASSWORD` | كلمة سر المدير الأول |
| `ADMIN_EMAIL` | بريد المدير (افتراضي `admin@nebras.local`) |
| `DB_URL` / `DB_USER` / `DB_PASSWORD` | اتصال القاعدة |
| `CORS_ORIGIN` | عنوان الواجهة المسموح |

## نسخ احتياطي واسترجاع
```bash
docker compose exec -T db pg_dump -U nebras nebras | gzip > backup-$(date +%F).sql.gz
```
**لا نعتبر النسخة موثوقة حتى تُجرَّب استعادتها على جهاز آخر.**
