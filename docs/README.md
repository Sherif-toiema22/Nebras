## قاعدة الصيانة
- كل قرار تصميم مهم = ملف جديد في `adr/` (لا نعدّل القديم، نكتب قرارًا جديدًا يلغيه).
- كل خطوة تنفيذ = ملف في `devlog/` بأربعة أقسام: ماذا فعلنا، لماذا، كيف نتحقق، النتيجة.
- لا نكتب في التوثيق أن شيئًا "يعمل" إلا بعد تجربته فعلًا.
